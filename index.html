Regression with Feed-Forward Neural Network (FFNN) and TensorFlow.js (TFJS)

Overview

This project shows the performance of three pre-trained neural networks to approximate a real-valued mathematical function. You can observe the training and testing datasets as well as the predictions of the different models.

Disscusion

All models consist of four layers – input, two dense layers, and an output layer. Each of the two dense (hidden) layers contains 100 neurons in both the noise-free and the best-fit model. The models were trained in batches of size 32 over 150 epochs. The Rectified Linear Unit (relu) was chosen as the activation function for the dense layers. The optimizer used is Adam with a learning rate of 0.025, and the loss function selected was the Mean Squared Error (MSE).
Overfit Model: The dense layers each contain 200 neurons, and the training was conducted over 400 epochs.

Observations:

The values in the training dataset are crucial for the quality of the model, as only 50 values are used for training. Despite the selected uniform distribution, the training data may still be randomly inhomogeneously distributed due to the small sample size (e.g., clustering around the center of the interval). In such cases, the prediction accuracy is significantly affected. Therefore, care must be taken to ensure that the training data is truly uniformly distributed and homogeneously covers the value range. The “ideally” trained model achieves the highest accuracy on the training data and on the noise-free test data. The “best-fit” model represents a good compromise between training and test loss. The “over-fit” model shows a significantly lower training loss compared to its test loss.

1) Technical Documentation

Frameworks and Libraries Used:

  • p5.js: A JavaScript library that contains predefined templates that make it easier to develop directly in the web browser. This project was almost entirely developed in the p5.js editor, which offers instant compilation and dynamic tracking of code changes. Interactive visual elements also work smoothly.
  • TensorFlow: For creating, training, saving, and loading neural networks. In addition, the required random values were generated using this library, e.g., with the method tf.randomUniform().
  • TensorFlow.js Vis: For visualizing model parameters, training progress, and predictions.
  • GitHub Pages: A hosting platform for static sites, used for public accessibility of the application. The project has been uploaded to GitHub, from where it is directly deployed via this option.

2) Subject-Specific Documentation

Implementation of Logic and Key Elements:

Prior to execution, the three models were trained, tested, and stored along with their corresponding data.

Workflow of the Online Application:

First, new uniformly distributed training and test data are generated using the getData() method. This method also handles the splitting of the dataset and the addition of noise. Subsequently, the three neural networks are loaded, and their predictions on the test data are computed using model.predict(). The use of pre-trained models significantly accelerates visualization and ensures an optimal user experience.
