Regression with Feed-Forward Neural Network (FFNN) and TensorFlow.js (TFJS)

Overview

This project shows the performance of three pre-trained neural networks to approximate a real-valued mathematical function. You can observe the training and testing datasets as well as the predictions of the different models.

Discussion

The models differ primarily in training epochs and architecture depth. The "ideal" model trained on noise-free data performed equally well on training and test sets (MSE ≈ 0.01), confirming that overfitting is not possible without noise. The "best-fit" model was trained on noisy data and achieved a balanced performance (MSE_train ≈ 0.051, MSE_test ≈ 0.069), suggesting good generalization. The "overfit" model, however, shows clear signs of overfitting with MSE_train ≈ 0.048 and MSE_test ≈ 0.089. This illustrates that longer training on noisy data leads to memorization of the noise. The values in the training dataset are crucial for the quality of the model, as only 50 values are used for training. Despite the selected uniform distribution, the training data may still be randomly inhomogeneously distributed due to the small sample size (e.g., clustering around the center of the interval). In such cases, the prediction accuracy is significantly affected. Therefore, care must be taken to ensure that the training data is truly uniformly distributed and homogeneously covers the value range. The results confirm that early stopping or validation sets are essential when noise is present.

1) Technical Documentation

All models consist of four layers – input, two dense layers, and an output layer. Each of the two dense (hidden) layers contains 200 neurons in both the noise-free and the best-fit model. The models were trained in batches of size 32 over 150 epochs. The Rectified Linear Unit (ReLU) was chosen as the activation function for the dense layers. The optimizer used is Adam with a learning rate of 0.01, and the loss function selected was the Mean Squared Error (MSE).
Overfit Model: The dense layers each contain 200 neurons, and the training was conducted over 1000 epochs.

Frameworks and Libraries Used:

  • p5.js: A JavaScript library that contains predefined templates that make it easier to develop directly in the web browser. This project was almost entirely developed in the p5.js editor, which offers instant compilation and dynamic tracking of code changes. Interactive visual elements also work smoothly.
  • TensorFlow: For creating, training, saving, and loading neural networks. In addition, the required random values were generated using this library, e.g., with the method tf.randomUniform().
  • TensorFlow.js Vis: For visualizing model parameters, training progress, and predictions.
  • GitHub Pages: A hosting platform for static sites, used for public accessibility of the application. The project has been uploaded to GitHub, from where it is directly deployed via this option.

Technical Specifications:

    • The application loads pre-trained models and loads a randomly pre-generated dataset.
    • The models were trained using a separate script in the p5 editor with the option to save the datasets and the model coefficients using buttons. This enabled a user-friendly and intuitive method to experiment with the models and find suitable parameters.
    • Mean Squared Error (MSE) is calculated and displayed for each model on training and test sets.
    • All diagrams are rendered dynamically via tfjs-vis.

2) Subject-Specific Documentation

Implementation of Logic and Key Elements:

Prior to execution, the three neural networks (models) were trained, tested, and stored along with their corresponding data. These models were implemented and trained using a consistent architecture with two hidden layers and ReLU activation. Each model was stored and reused to allow fast and reproducible visualization. The data generation simulates realistic conditions by adding Gaussian noise to the labels. The models demonstrate key Machine-Learning phenomena: good fit, generalization, and overfitting. The online app enables experimentation without server dependency. Sources included official TensorFlow.js documentation and StackOverflow examples.

Workflow of the Online Application:

First, pre-generated uniformly distributed training and test data are loaded using the loadDatasetFromFile() method. The loaded dataset is split into training and testing data and includes the addition of noise. Subsequently, the three neural networks are loaded, and their predictions on the test data are computed using model.predict(). The use of pre-trained models and data significantly accelerates visualization and ensures an optimal user experience.
